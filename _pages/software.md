## JAX-ALFA

**JAX-ALFA** — *Atmospheric LES For All* — is a [JAX](https://jax.readthedocs.io/)-based large-eddy
simulation (LES) framework for atmospheric boundary-layer flows.

- Spectral methods for horizontal derivatives; finite differences in the vertical
- FFT-based pressure solver
- Subgrid-scale closures with dynamic (Germano-type) coefficient computation
- Runs on CPUs and GPUs; single- and double-precision
- Written in Python / JAX; GPL-3.0-or-later

**[GitHub](https://github.com/Sukantabasu/jax-alfa)** · **[Documentation](https://jax-alfa.readthedocs.io/)**

If you use JAX-ALFA in research, teaching, or derivative software, please cite the GitHub
repository and documentation.

## Other code

**HybridWind** (MATLAB) — a hybrid profile–gradient approach for estimating surface fluxes.
[Bitbucket](https://bitbucket.org/sukantabasu/hybridwind) · [Zenodo](https://zenodo.org/record/1998633).
Reference: Basu (2018), *Boundary-Layer Meteorology* 170, 29–44.

**Thorpe $C_n^2$** (MATLAB) — estimating refractive-index structure-parameter ($C_n^2$) profiles
from a Thorpe-length-scale approach.
[Bitbucket](https://bitbucket.org/sukantabasu/thorpe-cn2/) · [Zenodo](https://zenodo.org/record/1998475).
Reference: Basu (2015), *Optics Letters* 40, 4130–4133.
