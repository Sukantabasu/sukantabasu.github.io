**JAX-ALFA** — _Atmospheric LES For All_ — is a [JAX](https://jax.readthedocs.io/)-based
large-eddy simulation (LES) framework for atmospheric boundary-layer flows, which I developed.

## Features

- Spectral methods for horizontal derivatives; finite differences in the vertical
- FFT-based pressure solver
- Subgrid-scale closures with dynamic (Germano-type) coefficient computation
- Runs on CPUs and GPUs; single- and double-precision
- Written in Python / JAX; GPL-3.0-or-later
- Under active development
